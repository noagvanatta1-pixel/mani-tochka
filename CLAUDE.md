# Копилка — контекст проекта для Claude

Telegram Mini App «Копилка» (учёт бюджета). Бот: @TheSavedMoney_bot, сайт: https://kopilka.website, канал: @noakopilka.
Тарифы: 7 дней пробный, 99 ₽/мес, 790 ₽/год, 1 990 ₽ навсегда. Поддержка: @Noagvanatta1. Скидка за подписку на канал (CHANNEL).

## Стек
- `server.js` — Node.js, SQLite (`node:sqlite`), бот на long polling, платежи, напоминания. Раздаёт `index.html`, `privacy.html`, `terms.html`.
- `index.html` — всё приложение одним файлом на чистом JS внутри IIFE. Темы через `html[data-theme=...]`, действия через делегированный `ACT` по `data-act`, окна через `sheet(html)`.
- Сервер: Москва, Caddy + systemd-сервис `mani`, переменные в `/etc/mani.env`. Обновление после пуша в main:
  `curl -fsSL https://raw.githubusercontent.com/noagvanatta1-pixel/mani-tochka/main/install.sh | bash -s kopilka.website`
- Владелец: переменная `OWNER_ID`. Команда владельца в боте `/post текст` (или фото с подписью `/post текст`) публикует в канал с кнопкой.

## Что сделано (последнее)
Свайпы (профиль только с главной, между вкладками влево/вправо), шторка профиля, кредиты (карточки, быстрые платежи 10/25/50%/полное погашение, активные/закрытые), цели (неоновая карточка, фото), подушка безопасности (цель `cushion:true`, расчёт от расходов, откладывать 10/25/50% дохода, всегда основная), «Безопасно потратить сегодня» учитывает лимиты, платежи, кредиты и планы целей, запоминание личный/семейный бюджет (`KEY_scope`), в аналитике блок «По дням» (месяц и неделя): нажатие на день открывает операции этого дня; `/post` принимает видео.

## Модель данных (S)
`S.debts`: `{id, kind:'loan'|'owed', name, total, pay, day, rate, due, note, payments[]}`. `S.goals`: `{id, name, target, img, contribs[], months, start, cushion?, cm?, pct?}`. `S.cats[].limit`, `S.recurring[]`, `S.ops[]`.

## Правила работы
- Тесты интерфейса: Playwright + Chromium из `/opt/pw-browsers`, viewport 390×844, файл `file:///.../index.html`. Синтаксис: вытащить самый большой inline `<script>` и `node --check`.
- Не использовать CSS-класс `.ghost` (занят кнопкой). Шторки профиля — `.curtain`.
- Не писать `pkill -f`/`pgrep -f "node server.js"` в одной команде с другими.
- Коммиты оканчивать строками `Co-Authored-By` и `Claude-Session`, как в предыдущих коммитах.
- Видео: вертикаль 1080×1920, неоновая тема `vio`, жёлтая плашка с @TheSavedMoney_bot, результат посередине, призыв в конце, без ложных обещаний, данные примера подписаны «Данные в ролике — пример».

## Предпочтения владельца
Отвечать по-русски, коротко и по делу, без лишних советов и похвалы. Если что-то не сделано, признавать прямо. Работает только с iPhone (Termius, Safari). Не просить пароли.
