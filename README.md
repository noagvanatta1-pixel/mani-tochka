# Мани.точка: приложение с сервером

Telegram Mini App для учёта расходов и накоплений. Каждый друг заходит через свой Telegram и видит только свои данные.

## Что в папке (5 файлов, все лежат в одной папке, без подпапок)

| Файл | Что это |
|---|---|
| `index.html` | само приложение |
| `server.js` | сервер: вход через Telegram, база данных, бот |
| `package.json` | описание проекта (ставить ничего не нужно, зависимостей нет) |
| `Dockerfile` | как запускать на хостинге |
| `README.md` | эта инструкция |

## Запуск шаг за шагом

### 1. Создайте бота
1. В Telegram откройте **@BotFather** и отправьте `/newbot`.
2. Придумайте имя и username (на `bot` заканчивается, например `my_money_point_bot`).
3. BotFather пришлёт **токен** (длинная строка с двоеточием). Сохраните его и никому не показывайте.

### 2. Загрузите файлы на GitHub
1. Создайте аккаунт на github.com, нажмите **New repository**, назовите, например, `mani-tochka`. Лучше сделать репозиторий **Private**.
2. Нажмите **Add file → Upload files**, перетащите все 5 файлов, нажмите **Commit changes**.

### 3. Разверните сервер
Подойдёт любой хостинг, где можно запустить Docker/Node и подключить **постоянный диск (Volume)**. Диск обязателен: на нём лежит база, без него данные пропадут при перезапуске. Пример на Railway (названия кнопок на сайте могут немного отличаться):

1. На railway.app: **New Project → Deploy from GitHub repo**, выберите репозиторий. Railway сам найдёт `Dockerfile`.
2. Откройте сервис → **Variables** и добавьте:
   - `BOT_TOKEN` = токен из шага 1
   - `DATA_DIR` = `/data`
3. Откройте **Volumes** (или Settings → Volumes), создайте диск и подключите его к пути `/data`.
4. В **Settings → Networking** нажмите **Generate Domain**. Получится адрес вида `https://mani-tochka.up.railway.app`.
5. Добавьте ещё одну переменную `APP_URL` = этот адрес целиком (с `https://`, без `/` в конце). Сервис перезапустится.

В логах должно появиться: `Мани.точка запущена…` и `Бот: @ваш_бот`.

### 4. Проверьте
Откройте своего бота в Telegram и отправьте `/start`. Придёт кнопка **«Открыть Мани.точку»**. Кнопка меню «Открыть» рядом с полем ввода сообщения тоже настроится автоматически.

### 5. Позовите друзей
В приложении: **Настройки → Позвать друзей**. Либо просто пришлите ссылку на бота `https://t.me/ваш_бот`.

## Как это устроено
- Приложение отправляет серверу подпись Telegram (`initData`). Сервер проверяет её токеном бота, поэтому подделать чужой аккаунт нельзя.
- Данные каждого пользователя лежат отдельно в SQLite (`mani.db` в `DATA_DIR`). Фото целей хранятся отдельной таблицей.
- Если нет интернета, приложение работает из памяти устройства и отправит изменения, когда связь вернётся.
- Если открыть приложение на двух устройствах и менять данные одновременно, побеждает сохранение, которое пришло на сервер раньше: второе устройство получит актуальные данные и покажет уведомление.
- Любой пользователь может удалить свои данные: **Настройки → Удалить мои данные с сервера**.

## Важно знать
- **Приватность.** Как владелец сервера вы технически имеете доступ к базе. Честно скажите об этом друзьям и не заглядывайте в чужие данные.
- **Резервные копии.** Периодически скачивайте файл `mani.db` с диска хостинга (или настройте автоматические бэкапы тома).
- **Лимиты.** До 300 запросов в минуту на человека, фото до ~900 КБ (приложение само сжимает), до 30 фото на человека.
- **Вход действует 3 дня** с момента открытия приложения из Telegram. Если приложение висит открытым дольше, закройте его и откройте заново.
- Нужен Node.js 22.13 или новее (в `Dockerfile` уже указан Node 22).

## Запуск на своём компьютере (для проверки)
```
BOT_TOKEN=ваш_токен DISABLE_BOT=1 node server.js
```
Откроется на `http://localhost:3000`. Вне Telegram приложение работает в режиме «без аккаунта» (данные только в браузере): полноценный вход возможен только изнутри Telegram по HTTPS-адресу.

## Переменные окружения
| Переменная | Зачем |
|---|---|
| `BOT_TOKEN` | токен бота, **обязательно** |
| `APP_URL` | публичный https-адрес приложения (для кнопки в боте) |
| `DATA_DIR` | куда класть базу (на хостинге: путь к постоянному диску) |
| `PORT` | порт (хостинг обычно задаёт сам) |
| `DISABLE_BOT=1` | не запускать бота, только сайт и API |
| `INITDATA_MAX_AGE` | сколько секунд действует вход (по умолчанию 259200 = 3 дня) |
